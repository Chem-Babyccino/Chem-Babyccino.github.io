# 113 分科測驗化學 - 可嵌入網頁 HTML 題目包

內容：
- original/: 27 個原題解析檔。僅以題號呈現，不重刊完整官方題目。
- diagnostic/: 每題 2 個診斷式試題，共 54 檔。
- similar/: 每題 2 個類似題，共 54 檔。
- index.html: 總索引。
- manifest.json: 檔案清單。

嵌入範例：
```html
<iframe src="original/q01.html" style="width:100%;height:720px;border:0;"></iframe>
```

建議：把整個資料夾上傳到網站同一目錄，使用相對路徑嵌入。
